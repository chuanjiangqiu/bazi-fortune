# 八字每日运势评估

一个基于传统八字命理算法的每日运势评估工具，支持日运/月运/年运三级运势，包含综合评分、四维度解读与宜忌建议。

## 功能特性

- **八字排盘**：输入出生年月日时，自动计算四柱八字（年柱/月柱/日柱/时柱），包含天干、地支、纳音、藏干、十神标注
- **日主信息**：突出显示日主天干及其五行属性、阴阳属性
- **三级运势**：
  - 日运：当日运势综合评分与解读
  - 月运：当月运势概览
  - 年运：当年运势概览
- **四维度评分**：事业、财运、感情、健康四个维度分别评分与解读
- **今日宜忌**：根据日辰十神类型 + 地支关系动态生成宜做/忌做事项
- **确定性计算**：同一八字同一日期，无论测算多少次，结果完全一致
- **深色中国风**：深墨底色 + 金色点缀 + 朱砂红强调，优雅大气

## 技术栈

- **框架**：React 19 + TypeScript
- **构建工具**：Vite 8
- **样式**：Tailwind CSS 4 + shadcn/ui
- **路由**：react-router-dom 7
- **八字计算**：lunar-javascript（农历/八字/节气计算库）
- **动画**：framer-motion
- **图标**：lucide-react

## 核心算法

### 十神计算
根据日主天干与目标天干的五行+阴阳关系，查表返回十神名称（正官/七杀/正印/偏印/比肩/劫财/食神/伤官/正财/偏财）。

### 地支关系判定
判断日辰地支与命局四个地支之间的六合、三合、半三合、六冲、三刑、自刑、六害关系。

### 运势评分公式
```
综合分 = 基准分(50) + 十神基准分 + 地支修正分 + 五行平衡修正分
```
结果 clamp 到 0-100 区间。

### 十神基准分（固定值）
| 十神 | 分数 | 十神 | 分数 |
|------|------|------|------|
| 正印 | +22 | 偏印 | +10 |
| 正官 | +20 | 七杀 | -15 |
| 正财 | +18 | 偏财 | +8 |
| 食神 | +15 | 伤官 | -8 |
| 比肩 | +5 | 劫财 | -5 |

### 地支修正分
| 关系 | 分数 | 关系 | 分数 |
|------|------|------|------|
| 六合 | +10 | 六冲 | -15 |
| 三合 | +10 | 三刑/自刑 | -10 |
| 半三合 | +10 | 六害 | -5 |
