# 大运流年推算

## 大运起运年龄与排法

### 步骤一：确定顺逆

| 性别 | 年干阴阳 | 方向 |
|------|----------|------|
| 男 | 阳年（甲丙戊庚壬） | 顺排 |
| 男 | 阴年（乙丁己辛癸） | 逆排 |
| 女 | 阳年 | 逆排 |
| 女 | 阴年 | 顺排 |

> 年干阴阳以年柱天干为准（注意：立春前用上一年干支）

### 步骤二：计算起运年龄

- 顺排：从出生日到**下一个节**（非气）的天数 ÷ 3 = 起运岁数
- 逆排：从出生日到**上一个节**的天数 ÷ 3 = 起运岁数
- 三天折一年，一天折四个月，一个时辰折十天

**节与气的区别**：
- **节**= 立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒
- **气**= 雨水/春分/谷雨/小满/夏至/大暑/处暑/秋分/霜降/小雪/冬至/大寒

### 步骤三：排列大运干支

- 顺排：从月柱**下一个**干支开始，依次向后排，每步 10 年
- 逆排：从月柱**上一个**干支开始，依次向前排，每步 10 年

### 步骤四：检查刑冲害

排出每步大运后，**必须**检查大运地支与原局四柱地支是否有：
- 六合、六冲
- 三刑（三支齐全才成立）
- 六害、相破
- 半合（标注"半合"，力量弱于三合强于六合）

有刑冲害的大运需在输出中标注（如"戌丑刑=内心纠结"）。

**三合局成立条件**：三合局必须三支齐全才成立，仅两支只是半合。

### 完整计算示例

> 男命，庚寅年，亥月(10月)，出生日12月6日，顺排
> 1. 年干庚=阳干 → 男阳年顺排
> 2. 顺排：从出生日12月6日到下一个节气"大雪"(约12月7日)约1天 → 1天÷3 ≈ 0岁4个月起运
> 3. 顺排从月柱下一个干支：丁亥→戊子→己丑→庚寅...
> 结果：0岁4月起运，第一步戊子(0-10岁)，第二步己丑(10-20岁)...

> 示例：月柱癸丑，男命阴年逆排
> - 起运年龄4岁
> - 第一步：壬子（4-13岁）
> - 第二步：辛亥（14-23岁）
> - 第三步：庚戌（24-33岁）
> - 第四步：己酉（34-43岁）
> - 第五步：戊申（44-53岁）

## 流年精排

### 评分标准

| 评分 | 含义 | 判定条件 |
|------|------|----------|
| ★★★★★ | 大吉年 | 用神透干到位 + 吉神齐聚 + 无刑冲 |
| ★★★★ | 吉年 | 用神到位或忌神有制化 + 部分吉神 |
| ★★★☆ | 中等偏好 | 用忌参半但喜略多 |
| ★★★ | 平年 | 用忌参半，无大吉大凶 |
| ★★☆ | 小凶年 | 忌神旺但有吉星缓解 |
| ★★ | 凶年 | 忌神透干 + 刑冲 + 无吉星 |

### 喜忌列标注规则

| 符号 | 含义 |
|------|------|
| ★ | 喜（流年干支包含用神五行，或对日主有利） |
| ⚠ | 忌（流年干支包含忌神五行，或对日主不利） |
| ★⚠ | 先喜后忧或喜忌交织（喜忌力量相当） |

判定逻辑：
- 流年天干地支包含用神五行 → ★
- 流年天干地支包含忌神五行 → ⚠
- 既有喜又有忌 → ★⚠
- 用忌力量对比：用神透干 > 用神藏支；忌神透干 > 忌神藏支

## 流年神煞叠加

命盘神煞是"出厂设置"，流年神煞是"每年追加"。流年干支带入的贵人、羊刃等会显著影响当年运势。

### 流年神煞查法

**1. 流年天乙贵人**：流年地支是否为命主的天乙贵人地支
- 如命主日干辛，天乙贵人在寅午，则流年寅年或午年=贵人年

**2. 流年与日柱关系**
- 流年与日柱干支相同 = 伏吟（反复、纠结）
- 流年与日柱干支对冲 = 反吟（动荡、变动）

**3. 流年遇禄/刃**
- 流年地支 = 日干之禄 → 禄年，事业有实底
- 流年地支 = 日干之刃 → 刃年，激烈但易冲动

**4. 流年遇桃花**
- 日支查：申子辰见酉、寅午戌见卯、亥卯未见子、巳酉丑见午
- 年支查：同上规则，用年支替代日支
- 流年地支逢桃花 → 感情活跃年

**5. 流年遇驿马** → 变动、出行、搬迁年
**6. 流年遇华盖** → 思考深入、孤独感强、适合研究创作
**7. 流年遇文昌** → 学习考试有利、灵感强

**8. 流年天干与日干合**：日干被合=日主被"绑住"
- 丙辛合→辛金日主被丙火合住，整年身不由己
- 年干被合=长辈/外部牵制
- 月干被合=上司/父母牵制
- 时干被合=子女/投资牵制

**9. 流年冲命局**
- 流年与月柱天合地合 → 外力助攻年
- 流年冲月支 → 冲破格局，大变动
- 流年冲日支 → 冲夫妻宫，感情波动
- 流年冲时支 → 冲子女宫/事业宫

## 感情时间线查询流程

当用户问"最近爱情有什么大变"/"今年感情如何"时：

1. 确定当前流年干支
2. 检查流年官星/财星（女命看官，男命看财）是否透干或到位
3. 检查流年桃花星是否到位
4. 检查流年天干是否与日干合（被合=身不由己）
5. 检查流年地支是否冲动夫妻宫（日支）
6. 结合用忌判断吉凶：官星/财星为用神且到位=好变动；为忌神且到位=波折
7. 给出具体时间窗口（如"今年下半年"/"明年春天"）
