# 排盘基础

## 农历转公历

用户提供农历日期时，必须先转换为公历（用万年历验证，不要简单加减）。

**常见参考点**：
- 2008 春节（正月初一）= 公历 2 月 7 日
- 2007 春节 = 公历 2 月 18 日
- 闰月需特别处理（查万年历确认）

如不能确定，用 web_search 搜索验证。

## 年柱推算

**立春换年柱**：公历 1 月出生的人可能还在前一年的年柱（立春通常在 2/3-5）。

公式：`(年份 - 4) % 60` → 六十甲子序号。

## 月柱推算（五虎遁）

根据年干定正月（寅月）天干：

| 年干 | 正月（寅月）天干 |
|------|------------------|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

## 时柱推算（五鼠遁）

根据日干定子时天干：

| 日干 | 子时天干 |
|------|----------|
| 甲、己 | 甲子 |
| 乙、庚 | 丙子 |
| 丙、辛 | 戊子 |
| 丁、壬 | 庚子 |
| 戊、癸 | 壬子 |

## 日柱推算

使用已知参考日推算：`2008-01-21 = 辛酉`（序数 57）

```python
from datetime import date
d0 = date(2008, 1, 21)  # 辛酉=57
d1 = date(target_year, target_month, target_day)
delta = (d1 - d0).days
seq = (57 + delta) % 60
天干 = ['甲','乙','丙','丁','戊','己','庚','辛','壬','癸']
地支 = ['子','丑','寅','卯','辰','巳','午','未','申','酉','戌','亥']
日柱 = 天干[seq%10] + 地支[seq%12]
```

## 子时归属（重要）

**早子时（0:00-0:59）** → 归当天
**夜子时（23:00-23:59）** → 归次日

**夜子时的日柱和时柱天干都要用次日推算**：
- 日柱干支取次日的干支
- 时柱天干用次日的日干按五鼠遁推算

例：10月15日23点出生 → 日柱用10月16日的干支，时柱天干用16日天干推时干。

## 闰月处理

农历闰月需特别处理：
- 月柱**不变**（闰月与前一月共用月柱）
- 但需要标注是闰月
- 闰月出生建议 web_search 确认

## 真太阳时（可选）

如果用户提供出生地点，可做真太阳时校准：
- 出生地经度 vs 北京时间基准（东经 120°）
- 每差 1° 约 4 分钟
- 公式：`真太阳时 = 北京时间 + (出生地经度 - 120) × 4分钟`
