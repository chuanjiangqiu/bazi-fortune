# 陷阱与注意事项（详细版）

## 一、基础排盘陷阱

### 1. 农历转公历

必须用万年历验证，**不能简单加减**。用 `datetime` 计算日干支时用固定参考点推算。

### 2. 时辰至关重要

差一个时辰，时柱完全不同。**必须确认时辰再排盘**。如果不确定，给出时辰范围让用户选择。

### 3. 立春分界

年柱以**立春**为界，**不是春节**。1 月底 2 月初出生的人容易搞错年柱。

### 4. 节气分界

月柱以**节气**为界（立春/惊蛰/清明...），**不是农历初一**。

### 5. 子时归属

- 早子时（0-1 点）→ 归当天
- 夜子时（23-24 点）→ 归次日

**夜子时（23-24点）的日柱和时柱天干都要用次日推算**：
- 日柱干支取次日的干支
- 时柱天干用次日的日干按五鼠遁推算

例：10月15日23点出生 → 日柱用10月16日的干支，时柱天干用16日天干推时干

### 6. 闰月

农历闰月需特别处理，月柱**不变**但需要标注闰月。建议 web_search 确认。

### 7. 盘面冲突

如果合冲刑害互相矛盾（如既合又冲），**以合为主，冲为辅**。

## 二、身强身弱陷阱

### 8. 不能只数五行

身强身弱**不能只数五行个数**，必须结合：
- 月令（月支对日主的旺衰影响最大）
- 日支根气
- 透干
- 合冲

判断口诀：得令+得地+得势=身强；失令+失地+失势=身弱；中间看合冲偏向。

### 9. 身强身弱是判断基础

身强喜克泄耗，身弱喜生扶。**搞反喜忌全错**。

### 10. 比肩透干计分

⚠️ **日主本身不算比劫透干**！只看年干、月干、时干。日干是"我"，不是"帮我的"。

### 11. 合局引动藏干

当四柱形成六合或半合（如寅亥合木、亥卯半合木）时，合局中的藏干力量远超"藏而不透"。

寅亥合木让寅中甲和亥中甲的力量激活。**身强身弱评分中，合局引动的藏干财官杀食应按"半透"对待**（减分 0.5-1），不能只标"藏而不透 +0"。

### 12. 亥月调候

调候速查表只覆盖子月和丑月，但亥月末（农历十一月初约公历 12 月初）已是深冬，辛金亥月生人同样需要火来调候暖局。

补充：亥月生人若水冷金寒，也需考虑火调候，但力度较子月稍轻。

## 三、男女命陷阱

### 13. 女命大运方向

阴年（乙丁己辛癸年）顺排，阳年（甲丙戊庚壬年）逆排。**与男命相反**。

### 14. 女命婚姻

女命看官星（正官=正缘，七杀=偏缘），**与男命看财星不同**。爱情板块必须区分。

### 15. 女命伤官见官大忌

女命伤官透干+正官透干（伤官见官）为婚姻大忌，主感情波折、婚姻不顺甚至多婚。

需在爱情板块重点标注并给出化解建议（晚婚、找年龄差距大的伴侣、用印星制伤官等）。

**严重程度分级**：
- 伤官旺官弱 → 克夫明显
- 伤官弱官旺 → 有波折但可控
- 有印星制伤官 → 凶中带吉

## 四、神煞陷阱

### 16. 桃花要查四柱所有地支

年支、月支、日支、时支都要查，**不能只查日支**。
- 年支桃花 = 外在形象桃花
- 日支桃花 = 核心感情桃花
- 时支桃花 = 晚年桃花

### 17. 流年神煞叠加

**不要只看命盘神煞**。流年逢天乙贵人可能比命盘天乙更重要——命盘贵人说"你有这个潜质"，流年贵人才是"贵人今年来了"。

### 18. 半合

三合局缺一支叫半合，力量弱于三合但强于六合。如申子（缺辰）为半合水局。

### 19. 伏吟反吟

- 流年与日柱相同 = 伏吟（反复、纠结）
- 流年与日柱对冲 = 反吟（动荡、变动）

伏吟分位置：
- 年柱伏吟 = 长辈反复
- 月柱伏吟 = 事业反复
- 日柱伏吟 = 自身反复
- 时柱伏吟 = 子女反复

### 20. 自刑

辰辰、午午、酉酉、亥亥为自刑，命主容易自我纠结、内耗。

### 21. 合化条件

不是所有合都能化，需看：
- 化神是否有根
- 季节是否当令

寅亥合木通常只合不化（需木旺季节才化）。

## 五、用神陷阱

### 22. 用神会变

用神不是一成不变的。大运流年改变了五行力量的平衡，用忌可能翻转。

原局用神在大运中可能变成忌神（如身弱用印，走印运身变强后印反为忌）。**每步大运都要重新评估喜忌**。

### 23. 从格判断

身弱到极点且无印比帮身时，可能构成从格。从格类型：
- 从财格：满盘财星 → 用神为财
- 从杀格（从官格）：满盘官杀 → 用神为官杀
- 从儿格（从食伤格）：满盘食伤 → 用神为食伤
- 从势格：财官食伤混杂不纯 → 用神为最旺之五行

**从格判断流程**：
1. 先按正常月令旺衰量化评分法计算总分
2. 如果总分 ≤ -5（身弱明显），再检查从格三条标准
3. 三条全满足才论从格，缺一则不论
4. 从格成立后用忌反转

**从格不成立**则按身弱明显处理，用神取印比帮身（正常扶抑）。

**从格判断标准（三条全满足才论）**：
1. 日主在地支无根（无禄刃长生墓库）
2. 月令为克泄耗日主之五行
3. 全局无有力帮身之五行

**从格用忌反转**：从格后用忌完全反转——顺势为吉、逆势为凶。

### 24. 调候-扶抑冲突

夏季火旺需水调候、冬季水旺需火调候，调候用神可能与其他用神冲突。

当调候与扶抑冲突时，**先论调候**（夏天出生的命盘，即使身强也要考虑水来降温）。

**操作步骤**：
1. 先判断是否需要调候（夏月/冬月/亥月）
2. 确定调候用神
3. 再看扶抑用神
4. 两者一致 → 完美
5. 两者冲突 → 找"既调候又不伤用神"的五行
6. 找不到兼顾的 → 调候优先，忌神流年大运需特别标注

## 六、合冲刑害陷阱

### 25. 流年天干与日干合

排流年时**必须**检查流年天干是否与日干（及年干、月干、时干）构成天干合。

- 日干被合 → 影响最大 = 日主被绊住，整年身不由己
- 年干被合 → 长辈/外部牵制
- 月干被合 → 上司/父母牵制
- 时干被合 → 子女/投资牵制

在流年关键词中用 ⚟ 符号标注合化对象，格式如"乙庚合时干⚚(投资被牵)"

### 26. 天干合化而非只合

天干五合有"合而不化"和"合而化"两种。

- 合而不化 → 只绊住两干减力
- 合化成功 → 产生新五行

输出时应注明"合而不化"或"合化×行"。

### 27. 不完整三刑不成立

三刑（寅巳申、丑戌未）**必须三支齐全才构成刑**。仅两支相遇（如寅巳无申）不算刑，只是普通冲克关系，力量远弱于完整三刑。

### 28. 合破共存以合为主

当六合与相破共存于同一对地支（如寅亥既是六合又是相破），**以六合为主**，相破影响极弱可忽略。

## 七、报告输出陷阱

### 29. 所有时间线必须面向未来

财富曲线、感情时间线、关键时间点都必须**从命主当前年龄开始往后画**。

不要画已经过去的年龄段（"15 岁起步期"之类的）——命主已经经历过了，看了没用。计算当前年龄（当前年份-出生年份），找到当前所在大运，从那里开始。

**这是命盘报告最常见的用户不满**：命理师画了一堆过去的曲线，用户说"我现在都 42 了，这有啥用"。

### 30. 当前大运标记

输出大运总览时，**必须**根据命主年龄标注 ←当前 在哪步大运，不要靠猜。

### 31. 大运地支与原局刑冲

排大运时**必须**检查大运地支与原局四柱地支是否有刑冲害关系（如戌丑刑、子午冲等），在大运解说中标注影响。

- 戌丑刑 = 内心纠结/规则冲突
- 子午冲 = 水火交战/情绪波动

### 32. 紫微命宫计算验证

公式结果必须用传统口诀交叉验证。

实际案例：酉月未时 → 公式 (8-8+2)%12=2 → 寅（太阳），口诀"寅起正月→八月在酉→从酉逆数至未→酉申未午巳辰卯寅丑子亥戌→寅" → 太阳 ✓

如果脚本输出与公式不符，检查：
- 索引是否从 0 开始
- 月数映射是否正确
- dizhi[0] 是否是 '子'

## 八、输出一致性陷阱（最常见错误来源）

生成报告后**必须**逐项交叉验证以下一致性：

- **紫微命宫**：标题副标题中的命宫主星必须与事业板块的紫微命宫一致
- **大运名称**：感情时间线、大运总览、财富曲线中的大运名称必须**完全一致**（如当前大运是辛亥，所有地方都必须写辛亥）
- **年龄**：所有年龄数字必须用 `当前年份 - 出生年份` 计算，**不能硬编码 42 岁**之类的错误值
- **用忌标注**：流年精排中的喜忌 ★/⚠ 必须与用忌结论一致

**验证方法**：生成完整报告后，搜索关键词（如"命宫""大运""岁"）检查是否有多处不一致。
