# 紫微斗数与灵数

## 紫微命宫推算

**公式**：
```
命宫地支序号 = (月数 - 时辰数 + 2) mod 12
```
结果 0-11 对应 子-亥。

**月数映射**（节气月地支序号，不是农历月）：
- 寅月=1, 卯月=2, 辰月=3, 巳月=4, 午月=5, 未月=6
- 申月=7, 酉月=8, 戌月=9, 亥月=10, 子月=11, 丑月=12
- 立春前出生用上一年月支序号

**时辰数**：子时=1，丑时=2，...，亥时=12

⚠️ **索引从 0 开始**：公式结果 0=子，1=丑，2=寅...11=亥。实现时 dizhi[0] 必须是 '子'。

### 传统口诀验证

"寅起正月→顺数到出生月→逆数到出生时辰"

验证示例：三月(3)午时(7) → (3-7+2) mod 12 = 10 = 戌
口诀：寅起正月→三月在辰，从辰逆数至午时→辰子丑寅卯辰巳午 = 戌 ✓

### 紫微命宫计算陷阱

1. **索引从 0 开始**：公式结果 0=子，1=丑，2=寅...11=亥
2. **月数映射**：酉月=8，未时=8。计算 (8-8+2)%12=2，对应寅（太阳），不是丑（天机）
3. **验证方法**：用传统口诀"寅起正月→顺数到月→逆数到时"交叉验证
4. **常见错误**：把月数当农历月（如 9 月）而非节气月序号（酉月=8）

## 紫微身宫推算

**公式**：
```
身宫地支序号 = (月数 + 时辰数) mod 12
```
结果 0-11 对应 子-亥。

**口诀**：寅起正月→顺数到出生月→顺数到出生时辰

验证示例：正月(1)卯时(4) → 身宫 = (1+4) mod 12 = 5 = 巳
口诀：寅起正月→正月在寅，从寅顺数至卯时→寅子卯丑辰寅巳卯 = 巳 ✓

## 灵数计算

**出生灵数**：出生年月日各位数字相加，反复相加至个位数。

例：2008-02-16 → 2+0+0+8+0+2+1+6=19 → 1+9=10 → 1+0=1
灵数 1，大限灵数 19。
