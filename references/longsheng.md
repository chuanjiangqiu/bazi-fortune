# 长生十二运

## 基本概念

日主在**四柱地支**中所处的十二个生命周期阶段，反映日主在那一柱的"活力"。

| 运 | 含义 | 类比 |
|----|------|------|
| 长生 | 出生、萌芽 | 婴儿 |
| 沐浴 | 嫩苗、未成型 | 洗澡 |
| 冠带 | 初步长成 | 青年 |
| 临官（禄）| 身强有力 | 壮年 |
| 帝旺 | 极盛 | 巅峰 |
| 衰 | 开始走下坡 | 中年 |
| 病 | 虚弱多病 | 老年 |
| 死 | 终结 | 临终 |
| 墓（库）| 收藏 | 入土 |
| 绝 | 彻底消失 | 灰飞烟灭 |
| 胎 | 重新萌芽 | 投胎 |
| 养 | 孕育 | 怀孕 |

## 阳生阴死顺逆

**核心规则**：天干分阳/阴，决定十二运在地支的走向。

| 阳干 | 阴干 |
|------|------|
| 甲 丙 戊 庚 壬 | 乙 丁 己 辛 癸 |

- **阳干男 / 阴干女**：顺行（从长生→沐浴→…→养）
- **阴干男 / 阳干女**：逆行（从长生→沐浴→…→养，但方向相反）

> 注：传统上**不分男女只看天干阴阳**，但也有流派分男女。本表按"不分男女"为准。

## 辛金十二运表

**辛 = 阴干 → 逆行**（主流子平真诠派：长生在子，逆数）

| 支 | 十二运 |
|----|--------|
| 子 | 长生 |
| 亥 | 沐浴 |
| 戌 | 冠带 |
| 酉 | 临官 |
| 申 | 帝旺 |
| 未 | 衰 |
| 午 | 病 |
| 巳 | 死 |
| 辰 | 墓 |
| 卯 | 绝 |
| 寅 | 胎 |
| 丑 | 养 |

> **速记**：辛金长生在**子**（主流派），逆数到酉=临官（辛禄位=临官，**不是长生**）。
> ⚠ 注：少数"禄即长生"派认为辛金长生在酉，但**业界主流**（《渊海子平》《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》）均用"长生在子"——本表与脚本 `scripts/bazi_calc.py` 一致采用主流派。

## 命主实测

**四柱**：丁亥 癸丑 辛酉 乙未

| 柱 | 地支 | 辛金十二运 |
|----|------|-----------|
| 年 | 亥 | 沐浴 |
| 月 | 丑 | 养 |
| 日 | 酉 | 临官 |
| 时 | 未 | 衰 |

**解读**：
- 日支酉=**临官**（辛禄位）：日支为根基所在，**根基稳健**
- 月支丑=**养**：月令失气，**创业期需自己积累**（养=还在孕育）
- 年支亥=**沐浴**：祖上/少年根基未实（沐浴=未成型）
- 时支未=**衰**：晚年开始走下坡，需提前布局（衰=中年后的体力精力下降）

## 用法

### 在身强身弱评分中

十二运的临官/帝旺/长生 → **强根加分**
十二运的墓/绝/死/病/胎/养 → **弱根减分或零分**

> 实际规则**已包含在 `references/strength-scoring.md` 的月令+日支根气+藏干权重里**，
> 不需要单独再加系数。十二运在这里主要是**质性描述**（给用户看"日支是禄所以强"）。

### 在输出报告中

**建议位置**：参考 `templates/full-report.md` 的"基础信息"段，作为四柱地支的注解：

```markdown
| 柱 | 地支 | 藏干主气 | 辛金十二运 |
|----|------|----------|-----------|
| 年 | 亥 | 壬 | 沐浴 |
| 月 | 丑 | 己 | 养 |
| 日 | 酉 | 辛 | 临官 |
| 时 | 未 | 己 | 衰 |
```

### 特别注意

1. **沐浴** 又称"桃花沐浴"，命主地支为沐浴=桃花位所在（参考 `references/ziwei-lingshu.md`）
2. **墓（库）** 区分：
   - 墓：有本气藏干但被封存，需要**刑冲**才能打开
   - 库：同墓，传统上一致
3. **胎/养** 都是"还在孕育"，力量很弱
4. **帝旺** 极盛但"过刚易折"，**墓**反而能"收藏精气"

## 与用神的关系

| 十二运 | 适合做用神? |
|--------|------------|
| 长生/临官/帝旺 | **是**：身强首选 |
| 冠带/墓/养 | 中性，**看组合** |
| 沐浴/衰/病/死/绝/胎 | **慎用**：本就虚弱，再做用神无力 |

> 实际用神**不直接看十二运**，还是看五行生克 + 身强身弱 + 调候。十二运是辅助参考。
