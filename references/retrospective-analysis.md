# 命盘回顾验证法

## 目的

用户常问「以前发生过什么事」——这是在用**已知人生大事**反向验证排盘是否准确。本文档标准化该流程。

---

## 核心思路

**大运 = 人生十年主题**，**流年 = 具体触发点**。已知事件 → 定位所在大运/流年 → 检查十神/神煞/刑冲是否吻合。

---

## 标准输出结构

### 1. 大运时间轴表

| 大运 | 年龄 | 干支 | 十神(干/支) | 核心主题 | 关键年份 |
|------|------|------|-------------|----------|----------|

### 2. 关键流年逐行核对

| 年份 | 流年 | 信号 | 可能事件 | 验证点 |

**信号列**包含：十神透干、桃花/贵人/驿马/禄刃、冲合刑害、伏吟反吟、财库开合

## 信号→事件映射速查

| 信号 | 常对应事件类型 |
|------|----------------|
| **正官/七杀透干** | 入学、考试、升职、签合同、进入体制/大厂、受规矩管束 |
| **正财/偏财透干 + 财库(辰戌丑未)到位** | 考上、拿奖、第一桶金、买房、投资收益、分红 |
| **食神/伤官透干** | 创作爆发、考证通过、技能突破、发表作品、面试表现好 |
| **印星透干** | 考研上岸、读书深造、拿学位、考公/司考/资格证、长辈提携 |
| **比劫透干** | 竞争激烈、合伙/团队项目、兄弟姐妹事、自主创业 |
| **桃花(子午卯酉)到位** | 谈恋爱、结婚、分手、情感波动、异性缘爆发 |
| **天乙贵人到位** | 关键贵人出现、被师长/领导提拔、逢凶化吉 |
| **驿马(寅申巳亥)冲动** | 搬家、换校、出国、出差、远程工作、环境大变 |
| **冲日支(夫妻宫)** | 感情变动、伴侣事、同居/分居、结婚/离婚 |

| **伏吟(流年=日柱/年柱/月柱/时柱)** | 反复、纠结、旧事重提、复盘、二次机会 |

## 进阶：反向推算出生时辰

若用户**不确定出生时辰**，可用「已知大事」反推：

1. 列出用户确定的 3-5 个大事（含年份）
2. 对 12 个时辰分别排盘、排大运
3. 哪个时辰的「大运+流年信号」最吻合已知大事 → 即为真实时辰
4. 若多个时辰均吻合 → 取「信号最强/最独特」者

**自动化脚本构想**：`scripts/rectify_birth_hour.py`（待创建）
- 输入：公历年月日、3-5 个(年份, 事件类型)
- 输出：最可能的时辰 + 置信度

## 注意事项

1. **别过度解读**：「信号→事件」是概率映射，非决定论。同一信号可对应不同事件（如「正官透干」既可指高考也可指入职）。
2. **以用户记忆为准**：模型推测仅作「核对清单」，用户确认才算数。
3. **优先查「独特信号」**：伏吟、反吟、驿马冲动、财库开合、桃花冲夫妻宫——这些信号特异性强，验证价值最高。
4. **记录「验证通过」的时辰**：确认无误后，可存入 memory 避免后续会话重复核对。
