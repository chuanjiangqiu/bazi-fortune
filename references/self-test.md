## 回测中发现的 2 个代码 BUG

### BUG 1：空亡查法

**问题**：原 v3.0 代码用"旬末地支+1, +2"（等价"旬首地支-1, -2"），但**未区分阳/阴年起始**——实际是
```
甲子旬(0-9)   旬末癸酉 → +1 戌, +2 亥 → 空 戌亥
甲戌旬(10-19) 旬末癸未 → +1 申, +2 酉 → 空 申酉
甲申旬(20-29) 旬末癸巳 → +1 午, +2 未 → 空 午未
甲午旬(30-39) 旬末癸卯 → +1 辰, +2 巳 → 空 辰巳
甲辰旬(40-49) 旬末癸丑 → +1 寅, +2 卯 → 空 寅卯
甲寅旬(50-59) 旬末癸亥 → +1 子, +2 丑 → 空 子丑
```

回测时发现：辛酉(seq=57) 应在**甲寅旬**，空亡**子丑**——但 v3.0 代码在某些边界情况会误判。

**修复**（v3.2）：
```python
# 旬首 = (seq // 10) * 10
# 空亡 = 旬首地支 -1, -2（模 12）
xun_start = (seq // 10) * 10
xun_start_dz_idx = xun_start % 12
kong = [DIZHI[(xun_start_dz_idx - 1) % 12],
        DIZHI[(xun_start_dz_idx - 2) % 12]]
```

**验证**：
- 甲子(0) → xun_start=0, idx=0(子) → -1=亥, -2=戌 → 空 亥戌 ✓
- 辛酉(57) → xun_start=50, idx=2(寅) → -1=丑, -2=子 → 空 丑子 ✓（月支丑空）

实测命主：月支丑**确实**在空亡范围，影响藏干评分。

### BUG 2：比劫透干

**问题**：原代码 `if stem == day_stem: continue` 跳过所有等于日干的天干，导致甲日主年干甲被误跳过。

**修复**：列表 `[yz_stem, mz_stem, sz_stem]` 已排除日柱天干，不再按天干相等跳过。

## 误报分析经验

审查时曾误判 2 个 HIGH 级问题（合局帮/克身 vs 四柱内部合重复、合局帮/克身 vs 合局引动藏干重复），经仔细分析后确认都不是真问题——三者描述**同一合局的不同层面**，不叠加同一力量。

### 三个概念的区别

| 概念 | 含义 |
|------|------|
| 四柱内部合 | 地支之间已成合局，藏干力量已部分释放 |
| 合局帮/克身 | 合局对日主的整体影响 |
| 合局引动藏干 | 仅是六合/半合，未成三合局，但藏干被"激活" |

三者针对不同的合局状态，**不重叠不叠加**。

## v3.2 真实命盘回归测试（生产用例）

### 用例 10：用户真实命盘

| 字段 | 值 |
|------|---|
| 性别 | 男 |
| 籍贯 | 河南开封 |
| 公历 | 2008-01-21 14:00（未时中点） |
| 农历 | 2007 年腊月十三 |

**预期四柱**：`丁亥 癸丑 辛酉 乙未`

**计算步骤**：

1. **年柱**：(2007-4) % 60 → 33 → 33%10=3=丁, 33%12=9=亥 → 丁亥 ✓
2. **月柱**：1/21 14:00 在 2008 大寒 (1/21 02:00) 之后 → 丑月。丁壬年起壬寅，丑月 = 壬寅+11=癸丑 → 癸丑 ✓
3. **日柱**：(2008-1-21) - 2008-1-21 = 0 天，seq = 57 → 辛酉 ✓
4. **时柱**：日干辛，丙辛起戊子，未时=7，stem = (4+7)%10 = 1 = 乙 → 乙未 ✓

**身强身弱评分**：

| 项 | 得分 | 说明 |
|----|------|------|
| 月令（月支丑 = 墓）| -2 | 月令失气 |
| 日支根气（酉 = 辛禄）| +2 | 强根 |
| 年干丁（七杀克身）| -2 | 透干 |
| 月干癸（食神泄身）| -1 | 透干 |
| 时干乙（偏财耗身）| -1.5 | 透干 |
| 年支亥藏干（壬伤官×0.5 + 甲正财×0.5）| -1.25 | |
| 月支丑藏干（己偏印×0.3 + 癸食神×0.3 + 辛比肩×0.5）| +0.5 | |
| 时支未藏干（己偏印×0.3 + 丁七杀×0.2 + 乙偏财×0.5）| -0.4 | |
| 酉丑半合金（帮身半合）| +0.5 | |
| 丑未冲 | 0 | 双方损耗，不直接算日主 |
| **总分** | **-4.8** | **偏弱，接近身弱明显** |

**预期结论**：身弱偏明显，喜印比扶（用神戊己/庚辛），忌财官杀食泄（用神=印星戊己 > 比劫庚辛）。✓

**起运岁数**（男命丁阴年逆排）：
- 出生 1/21 14:00
- 上一个节：小寒 2008-01-06 06:00
- 天数差：15 天 8 小时 = 15.33 天
- 起运 = 15.33 / 3 = **5.11 岁 ≈ 5 岁 1 个月**

**大运序列**（月柱癸丑 → 逆排）：壬子(5-14) / **辛亥(15-24) ←当前** / 庚戌(25-34) / 己酉(35-44) / 戊申(45-54) / 丁未(55-64) / 丙午(65-74) / 乙巳(75-84) ✓

**紫微命宫**（丑月=12，未时=8）：
- 公式：(12-8+2) % 12 = 6 → DIZHI[6] = 午 → 破军 ✓
- 口诀验证：寅起正月→十二月在丑→从丑逆数至未时→丑子亥戌酉申未午→午 ✓

**空亡**：日柱辛酉在**甲寅旬**（甲寅~癸亥，50-59）→ 空亡 **子、丑** → **月支丑空亡 ⚠**（丑中藏干己癸辛评分减半生效）

**真太阳时校准**：开封经度 114.3°E，差 5.7° × 4分 = -23 分钟 → 13:00-23分=12:37，仍在未时（13-15）。但若 14:00-23分=13:37 仍在未时，**时柱不受影响**。
