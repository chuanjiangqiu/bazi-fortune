# ASCII 五行雷达图

## 设计目标

把"金+4 / 水+3 / 木+2 / 土+1 / 火-3"这种数字化的五行评分，**变成一眼能看懂的图**。

## 五行布局（五边形）

按五行相生顺序（**木 → 火 → 土 → 金 → 水 → 木**）排列在五边形顶点：

```
                木
                ★
                │
            ╱   │   ╲
          ╱     │     ╲
        ╱       │       ╲
      水 ───────┼────── 火
        ★       │        ★
          ╲     │     ╱
            ╲   │   ╱
              ╲ │ ╱
                │
                ★
                土
```

## 强弱等级

| 符号 | 含义 | 数值范围 |
|------|------|----------|
| ★★★★★ | 极旺 | +5 及以上 |
| ★★★★  | 旺 | +3 ~ +5 |
| ★★★   | 偏旺 | +1 ~ +3 |
| ★★    | 中性 | 0 左右 |
| ★     | 偏弱 | -1 ~ -3 |
| ☆     | 弱 | -3 ~ -5 |
| ⊗     | 极弱 | -5 及以下 |

## 命主实测模板（丁亥 癸丑 辛酉 乙未）

```
        木（★★）             强度：+1
          ☆                      
          │                       
      ╱   │   ╲                  
    ╱     │     ╱                
  水 ☆ ───┼─── 火 ⊗              
（+3）    │    （-3）              
    ╲     │     ╱                
      ╲   │   ╱                  
          │                       
          ★                       
        土（★★★）               
        （+2）                    

金（★★★★★）                  +4  ←  最旺
```

## 关键规则

1. **极弱/极旺都需用注释标出**：
   - `⊗` 极弱 = 该五行对应的脏腑/情绪容易出问题
   - `★★★★★` 极旺 = 该五行过旺，**也失衡**（如水旺极=肾/泌尿过劳）

2. **配色建议**（文字版）：
   - 木 → 青色
   - 火 → 红色
   - 土 → 黄色
   - 金 → 白色
   - 水 → 黑色

3. **用神和忌神用框标出**：
   - 用神（喜）：外框 `┌─┐`
   - 忌神（忌）：外框 `┏━┓` 加红字

## 完整模板（直接复制到报告）

```markdown
## 五行强弱雷达

| 五行 | 等级 | 数值 | 状态 | 脏腑 |
|------|------|------|------|------|
| 金 | ★★★★☆ | +4 | 偏旺 | 肺/大肠/皮肤 |
| 水 | ★★★ | +3 | 偏旺 | 肾/膀胱/泌尿 |
| 木 | ★★ | +1 | 中性 | 肝/胆/情绪 |
| 土 | ★★★ | +2 | 偏旺 | 脾/胃/消化 |
| 火 | ⊗ | -3 | 极弱 | 心/小肠/血液 |

```
                木（★★）
                  ☆
                  │
              ╱   │   ╲
            ╱     │     ╲
          ╱       │       ╲
        水 ★★★ ───┼─── 火 ⊗
        （+3）    │    （-3）
            ╲     │     ╱
              ╲   │   ╱
                  │
                  ★★★
                土（+2）
```

**关键发现**：
- 火极弱（-3）= 心脏/血液循环/手腳易冷 → 急需火来暖局
- 金水双旺 = 寒湿体质 → 注意保暖 + 排湿
- 木中性 = 肝胆功能尚可 → 但不宜再克（甲乙木为忌神）
```

## 注意事项

- 五行数值由 `scripts/bazi_calc.py` 自动输出（看 `身强身弱评分` 段）
- 雷达图是**辅助可视化**，**不是命理规则本身**
- 极弱/极旺的判断标准是**相对值**（最强和最弱的差），不是绝对值
- 完整量化方法见 `references/strength-scoring.md`
